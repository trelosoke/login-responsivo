## Tecnologias utilizadas

- **Linguagens**: HTML e CSS.

- **Conceitos e técnicas**: Mobile-first, Media-Queries, Variáveis CSS, `calc()`, Unidades dinâmicas de viewport (`dvh`), Posicionamento (`position`, `float`), Transições, Estados interativos (`:hover`, `:active`, `:focus‑within`), Reset CSS com `box‑sizing: border‑box`, Fallback de fontes com `system‑ui`.

- **Ferramentas e Recursos**: Google Fonts (Material Symbols), Git e GitHub, GitHub Pages.

## Funcionalidades

- Layout responsivo que se adapta a três faixas de tela (mobile, tablet, desktop).

- Campos de entrada com ícones integrados e estados de foco, hover e ativo.

- Uso de unidades dinâmicas (dvh) para evitar rolagem indesejada no mobile.

- Transições suaves nos botões e no redimensionamento do container.

## Como executar localmente

- Clone o repositório e abra o arquivo `index.html` em qualquer navegador.
